# 🌐 CCNA Packet Tracer Labs

> A comprehensive collection of Cisco Packet Tracer labs demonstrating hands-on configuration, troubleshooting, and network design skills.

This repository serves as a practical portfolio of enterprise level networking concepts. It includes configurations for Layer 2 switching, IPv4 routing protocols, essential network services, and security implementations based on the CCNA standard.

## 🛠️ Technologies & Protocols
* **Switching:** VLANs, VTP, Transparent VLAN, STP (Spanning Tree Protocol)
* **Routing:** Static Routing, Inter-VLAN Routing, OSPF (Single-Area, Multi-Area, DR/BDR)
* **Services:** DHCP, NAT (Basic & PAT), NTP, Syslog, SNMP, SSH, Telnet
* **Security & HA:** Port Security, ACLs (Standard & Extended), HSRP
